Descripción del proyecto

Moto Routes API es una API REST creada como proyecto del módulo de desarrollo de aplicaciones web.

Su objetivo es proporcionar un servicio mediante el cual se puedan gestionar rutas para motocicletas almacenadas en una base de datos PostgreSQL.

Endpoints principales

Método Endpoint Descripción
GET /api/routes Obtiene todas las rutas.
GET /api/routes/:id Obtiene una ruta concreta.
POST /api/routes Crea una nueva ruta.
PUT /api/routes/:id Modifica una ruta.
DELETE /api/routes/:id Elimina una ruta.
