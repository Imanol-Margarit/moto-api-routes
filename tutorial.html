🏍️ Moto Routes API

Mini tutorial de utilización

Inicio Proyecto Tutorial Tecnologías

1. Iniciar el proyecto

Para ejecutar la API en local primero instalamos las dependencias del proyecto: 

npm install

Después podemos iniciar el servidor: 

npm run dev

2. Comprobar la API

Una vez iniciado el servidor podemos comprobar que está funcionando mediante el endpoint: 

GET /health

3. Probar con Postman

Postman permite realizar peticiones HTTP a la API y comprobar las respuestas del servidor.

Por ejemplo, podemos realizar una petición GET: 

GET http://localhost:3000/api/routes

La respuesta contiene las rutas almacenadas en la base de datos.
