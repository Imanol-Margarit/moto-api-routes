Tecnologías utilizadas

Node.js

Entorno utilizado para ejecutar JavaScript en el servidor.

Express

Framework utilizado para crear la API REST y gestionar las rutas HTTP.

PostgreSQL

Sistema de gestión de bases de datos utilizado para almacenar las rutas.

Docker

Utilizado para facilitar la configuración y ejecución de los servicios.

Postman

Herramienta utilizada para probar los endpoints de la API.
